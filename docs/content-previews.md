# Фото и обложки публикаций

Collector запрашивает изображения автоматически при очередном сборе:

- Instagram: `media_url` для IMAGE, `thumbnail_url` для VIDEO; у карусели — фото или обложку первого дочернего элемента. Видео не загружается как изображение. Отсутствие этих полей допустимо, в частности при ограничениях copyright. Источник: [официальный IG Media reference](https://developers.facebook.com/docs/instagram-platform/instagram-graph-api/reference/ig-media/).
- TikTok: `cover_image_url`, статичная обложка. Срок жизни ссылки — 6 часов согласно [официальному Video Object reference](https://developers.tiktok.com/docs/en/tiktok-api-v2-video-object).

`content.preview_url` — текущие метаданные, а не историческая аналитика. Новая непустая ссылка заменяет старую; отсутствие поля не стирает известную ссылку. Signed query сохраняется. При открытии dashboard нет запросов к provider API и token refresh: браузер загружает только изображение CDN без Referer, в рамках CSP. Файлы изображений сервер не скачивает и не архивирует. Разрешены HTTPS CDN домены `cdninstagram.com`, `fbcdn.net`, `tiktokcdn.com`, `tiktokcdn-us.com`, `tiktokcdn-eu.com`, `ibytedtos.com` и их поддомены. Другие CDN остаются недоступными, пока их не проверят и не добавят в Python validator, browser validator и CSP.

Миниатюры доступны в списке, последних публикациях и карточке публикации. Нажатие открывает изображение целиком без обрезки. Закрытие: кнопка, Escape или фон вокруг окна. Клавиатурный фокус удерживается native dialog и возвращается к исходной кнопке. При истечении ссылки/ошибке загрузки показана заглушка; доступ к самой публикации остаётся через permalink.

## Применение

Миграция `0004` добавляет nullable колонку только в `content`. Перед обновлением рабочего приложения необходимы обычная резервная копия и `alembic upgrade head` в выбранном deployment. Рабочая БД не мигрировалась при разработке этой функции. Пересобрать приложение после миграции; при следующем отдельном, разрешённом сборе появятся ссылки. Старые snapshots не изменяются. Повтор успешного UUID возвращает cached результат, поэтому для нового сбора нужен новый UUID.

Ссылки могут истечь между сборами. Просмотр страницы сам по себе их не продлевает. Автоматического API-запроса при ошибке картинки нет; обновление — через следующий сбор. Карусель показывает только первый элемент; полноценная галерея и проигрывание видео не реализованы.

## Проверки без реальных API

```sh
.venv/bin/python -m pytest -q tests/test_content_previews.py tests/test_dashboard.py tests/test_migrations.py
node tests/frontend_contract.mjs
# Playwright должен быть доступен; альтернативный путь к модулю — PLAYWRIGHT_MODULE.
# Для установленного Chrome можно задать PLAYWRIGHT_CHANNEL=chrome.
node tests/frontend_preview.mjs
```

Browser test использует временный профиль, перехватывает все запросы и подставляет фиктивные API/изображения. Он проверяет увеличение, клавиатуру, возврат фокуса, закрытие, ширину 320 px и истёкшую картинку. HTTP production API и credentials не используются.
