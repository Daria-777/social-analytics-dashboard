# Разделы дашборда

## Обзор
Текущие показатели аккаунтов и накопленные недельные значения. «Динамика показателей по дням» объединяет чистое изменение подписчиков и доступные значения активности за день из API. Изменение счётчика не означает число отдельных подписок и отписок. Пропуск между замерами обозначается интервалом; прирост не приписывается одному дню. Доступность ежедневных просмотров зависит от API платформы: отсутствие не заменяется нулём.

Обзор также показывает состояние сбора, ошибки и историю запусков. Фильтры публикаций его не ограничивают.

## Публикации
Обложки, названия, показатели и история отдельных публикаций. Фильтры по платформе, датам и разметке; сортировка по дате или просмотрам; список, графики и полная таблица. Название открывает историю. В списке и полной таблице — одна строка на публикацию: API имеет приоритет, при отсутствии доступного показателя используется другой источник. Для графика выбирается один замер с выбранным показателем. Значения разных источников не складываются и не дополняют друг друга. Другой источник можно выбрать фильтром; все замеры и дополнительные показатели остаются в истории публикации.

## Сравнение
Одна платформа, источник, формат, диапазон публикаций и выбранный показатель. По умолчанию сравниваются отдельные публикации: названия, значения и зелёная диаграмма. Доступна группировка по тегам. Неподходящие периоды и качества не объединяются. Маленькая выборка не доказывает эффективность формата.

## Наблюдения
Дополнительная статистика из Instagram Insights и TikTok Studio. AI-агент читает её через браузер и сохраняет штатным локальным импортом. Инструкция: [weekly-ai-agent.md](weekly-ai-agent.md). Сводки аккаунта отделены от публикаций, время и период сохраняются.

Подпись «AI-агент» определяется по сохранённому признаку запуска или `collection_method`. Самостоятельная форма и импорт также доступны; самостоятельный ввод имеет отдельную отметку. Старые записи неизвестного происхождения не приписываются агенту.

## Гипотезы
Учёт эксперимента: что проверяется, какой показатель и источник используются. Публикации связываются с гипотезой в истории. Агент может помочь сформулировать гипотезу; это не автоматический вывод о причинности.

## История публикации
Замеры, график распространения, доступные расчётные показатели, удержание, география, разметка темы / серии / хука и связи с гипотезами. Агент размечает реальную публикацию, самостоятельная правка тоже доступна.

## Способы сбора
«Автоматическое обновление по API» - штатный сбор доступных платформенных счётчиков. «AI-агент» - отдельное чтение Insights / Studio и разметка по содержанию; ему нужны браузерные инструменты. Платформенный источник и способ сбора - разные признаки. История и методы не переписываются при изменении подписи интерфейса.

Неизвестное обозначается «—», реальный ноль - «0». Часовой пояс определяется браузером. Источник, период и время доступны в «Примечаниях». Графики используют только сохранённые точки; отсутствующая ранняя история не восстанавливается.
