# Еженедельный AI-агент

API автоматически обновляет доступные счётчики. AI-агент дополняет их данными из браузерных Insights / Studio и разметкой публикаций. Это отдельная задача в вашем ИИ-сервисе, а не встроенный в FastAPI бот. Для работы нужны авторизованные браузерные инструменты и доступ к включённому дашборду.

Скопируйте этот промпт в задачу ИИ, которая настроила ваш проект:

```text
ДОПОЛНЯЙ МОЙ ДАШБОРД КАЖДУЮ НЕДЕЛЮ

Используй уже настроенный проект и мои подключённые аккаунты Instagram и TikTok. Раз в неделю читай их статистику через авторизованный браузер: Instagram Insights и TikTok Studio. API продолжает свой отдельный автоматический сбор. Не меняй настройки аккаунтов, не публикуй, не отправляй сообщения и не обходи ограничения.

Прочитай README, docs/manual-import.md и схему ImportBatch проекта. Найди локальный дашборд и приватный способ доступа. Секреты используй только локально, не показывай в чате, файлах отчёта или логах. Проверь, что открыт именно мой аккаунт. При истёкшей сессии или отсутствии доступа сообщи, где мне нужно войти; не заполняй поля догадками.

Проверь новые публикации. Сопоставляй их по точным ID платформы. Посмотри реальные первые секунды и весь ролик / слайды; заполни короткое название, тему, серию, формат, тип и текст хука, явный CTA. Не выдавай подпись за хук и не заменяй мою разметку без основания. Непроверенные поля оставь пустыми; основу разметки сохрани в заметках.

Прочитай доступные просмотры, зрителей, реакции, удержание, досмотр, источники трафика и географию. Сводки аккаунта и карточки публикаций сохраняй отдельно. Фиксируй время чтения с часовым поясом, показанный период и доказательство: текст или скриншот. Ноль сохраняй только при показанном нуле; неизвестное - null. Не придумывай границы периода. Противоречия сохраняй с отметкой anomalous, не исправляй числа платформы.

Сохраняй через штатный локальный импорт и PATCH /content/{id}/tags. Источники: instagram_ui и tiktok_studio. В raw_payload каждой записи добавляй collection_method: ai_agent и уникальный agent_run_id. Перед импортом сохрани пакет и его хеш; перед повторной отправкой проверь, что этот запуск ещё не внесён. Историю не перезаписывай и источники не складывай. Проверь сохранённые UUID, числа, источники и отображение в «Наблюдениях».

Если сервис поддерживает расписание, создай одну еженедельную задачу с этой инструкцией и укажи время выполнения. Если нет - сохрани инструкцию для повторного запуска; не обещай фоновую работу. Локальный дашборд должен быть включён, а браузерный доступ доступен агенту.

После запуска кратко сообщи число проверенных и размеченных публикаций, добавленных наблюдений и недоступные данные. Отделяй измерения от своих интерпретаций; не объявляй победителя по единичному ролику.
```

API-источники остаются `instagram_api` / `tiktok_api`. Агент использует `instagram_ui` / `tiktok_studio`; в `raw_payload` добавляет `collection_method: "ai_agent"` и уникальный `agent_run_id`. Самостоятельная форма ставит `collection_method: "manual"`. Старые записи без этих признаков не приписываются агенту. Статус `manual` в схеме - характеристика измерения, он не определяет, кто его собрал.
