# Social Analytics - личный дашборд

Готовая основа Instagram/TikTok с интерфейсом DASH. База: e194e2b.
Изменения этой копии: пустые ограничения username, UTC для сервера,
автоматический часовой пояс браузера. Метрики и интерфейс сохранены.
API, ручные наблюдения, история, сравнения, гипотезы и opt-in расписание.
Аккаунты, секреты, рабочая БД и Git-история владельца не включены.

Описание функций: [Разделы дашборда](docs/dashboard-sections.md).

## Для ИИ, настраивающего копию

Используй существующие файлы, сохрани интерфейс и поведение.
Не создавай замену по описанию. Настрой новый приватный .env и собственные
приложения Meta/TikTok владельца; примеры demo.account не являются аккаунтом.
Установи INSTAGRAM_EXPECTED_USERNAME / TIKTOK_EXPECTED_USERNAME из ссылок
владельца, проверив фактическую идентичность после авторизации.
Пустые defaults не являются согласием собирать любой аккаунт.
Часовой пояс интерфейса определяется браузером автоматически.
В config DISPLAY_TIMEZONE отвечает за серверный fallback, а не за браузер.

Нужен агент с доступом к файлам и терминалу. Плагины ИИ для приложения
не обязательны. Обычный чат без инструментов не запускает сервис.
Git нужен для получения кода; Docker Engine + Compose v2 для контейнеров.
Python 3.12+ нужен для локальных CLI OAuth/настройки вне контейнера.
Node.js нужен только для проверок JavaScript/браузера, не для работы сервиса.
Устанавливай недостающее из официальных источников; соглашения/системные
подтверждения оставь владельцу. Подписка/тариф инструмента не включены.

## Локальное окружение

python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock
.venv/bin/python -m pip install --no-deps -e .
.venv/bin/python -m app.cli.local_setup
docker compose -p social-analytics --env-file .env config -q
docker compose -p social-analytics --env-file .env up --build -d

Дашборд: http://127.0.0.1:8000/dashboard
Не печатай секреты из .env или Compose config. Получи ключ входа приватно.
Флаг --copy-key в local_setup использует clipboard macOS; на других системах
подготовь приватный ввод ключа без вывода в чат/логи.

Instagram setup: docs/instagram-api.md. TikTok: docs/tiktok-api.md.
Права/версии API сверяй с текущими официальными правилами при подключении.
Для HTTPS callback может понадобиться домен/туннель; открывай только callback,
а не dashboard/БД. Публичные /terms и /privacy - пример: адаптируй контакт
оператора и правила под конкретное приложение до регистрации в платформах.
TikTok token refresh: docs/tiktok-volume.md; расписание: docs/scheduler.md.
Сбор локально не работает при сне/выключении компьютера.

## Проверки

.venv/bin/python -m pytest -q
node tests/frontend_contract.mjs
node tests/frontend_ux_contract.mjs

Тесты изолируют HTTP и credentials; не запускай live-сбор в качестве тестов.
Для PostgreSQL integration нужна отдельная test_dash, не рабочая БД.
Проверь реальное подключение отдельно после согласия владельца.
Backup/restore: docs/local-deployment.md; сервер: docs/server-deployment.md.
Перезапуск не должен удалять volume с рабочими данными.

## Границы комплекта

Это личные независимые копии, не готовый многопользовательский сервис.
Реальная статистика зависит от согласия, типа аккаунта и прав платформы.
Сборка комплекта на другом компьютере и подключение чужих аккаунтов
не подтверждены; проверь их при настройке конкретной копии.
