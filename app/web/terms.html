Условия использования

Назначение

SOCIAL ANALYTICS Social Analytics — личное приложение одного владельца для анализа собственного контента Instagram и TikTok. Оно получает разрешённые данные профиля, публичных публикаций и их счётчиков через официальные API и сохраняет отдельные наблюдения с источником и временем в локальной базе данных.

Доступ и действия

Подключение аккаунта требует согласия владельца и доступных разрешений платформы. Социальные интеграции работают только на чтение: приложение не публикует контент, не отправляет сообщения, не изменяет комментарии и не выполняет социальные записи. Из dashboard можно добавлять локальные ручные наблюдения, теги и гипотезы.

Ограничения данных

Доступность показателей определяется платформой и предоставленным доступом. Отсутствующие значения остаются неизвестными. Данные API и интерфейса платформы могут различаться; аналитические связи не доказывают причинность и не гарантируют результат публикаций.

Локальная работа

Текущая версия предназначена для личного использования на локальном устройстве. Работа зависит от запущенного Docker Desktop и доступности API платформ. Управление аккаунтами и их разрешениями остаётся у владельца.

Эта страница описывает текущую реализацию и не является подтверждением юридической сертификации или одобрения приложения платформами.
